# 📊 Amazon Prime Report – Power BI Dashboard
## 📌 Project Overview

This project presents an interactive Power BI dashboard built using the Amazon Prime Video dataset.
The report highlights key insights about content distribution, genres, ratings, and release trends on the Amazon Prime platform.

## 🎯 Objectives

Analyze Amazon Prime content library

Identify trends in movie vs. TV show releases

Explore genre popularity

View country-wise content distribution

Visualize rating categories

Provide a clean and interactive Power BI dashboard for users

## 🛠 Tools & Technologies

Power BI Desktop

Power Query (Data Cleaning & Preparation)

DAX (Measures & Calculated Columns)
